# شرح خوارزمية المطابقة

هذا المجلد يشرح الخوارزمية التي يستخدمها Zaho Reconcile لمقارنة ملفين ماليين.

| الملف | المحتوى |
|---|---|
| `ALGORITHM.md` | الشرح الكامل خطوة بخطوة (يُقرأ في VS Code أو GitHub أو أي عارض Markdown). |
| `Zaho_Reconcile_Algorithm.pdf` | النسخة نفسها كملف PDF للطباعة والمشاركة، مع الرسوم التوضيحية. |
| `diagrams/` | الرسوم التوضيحية: مراحل المطابقة، طريقة الربط، شجرة التصنيف. |
| `example/` | مثال عملي صغير: ملفان يغطيان كل أنواع النتائج، والنتيجة الفعلية لكل سطر. |
| `_build/build.py` | يعيد إنشاء المثال والرسوم والـ PDF من الكود الحالي. |

## ملخص في سطور

1. يُقرأ كل ملف ويُحفظ كنص كما هو في Parquet، مع رقم السطر الأصلي.
2. يُعرف دور كل عمود (المرجع، المبلغ، الحالة، التاريخ، العملة، الرسوم) من اسمه وقيمه معًا، ويُختار عمود المرجع حسب تداخل القيم الفعلي بين الملفين.
3. الخدمة تحدد هل تُطابق الرسوم / الإيراد، والحالات تُقارن تمامًا بالأسماء المعتمدة فقط (أو تلقائيًا إن اختير ذلك).
4. خطوة التحقق تعرض المشكلات قبل التشغيل وتمنع التشغيل عند وجود أخطاء.
5. يُربط كل سجل بمرجعه (التكرار رقم n مع التكرار رقم n)، ثم ما بقي بالمبلغ واليوم عندما لا يوجد التباس.
6. يُقارن كل حقل بقاعدته، ويحصل كل سجل على تصنيف واحد؛ حقلان مختلفان أو أكثر = «اختلافات متعددة».
7. لكل استثناء أهمية ومبلغ معرض للخطر، ويُحفظ في MySQL للمراجعة، والنتائج الكاملة في Parquet والتقارير.

## إعادة إنشاء المستندات

من مجلد المشروع:

```
.venv\Scripts\python.exe docs\algorithm\_build\build.py
```

يحتاج Chrome أو Edge لإنشاء ملف PDF.
